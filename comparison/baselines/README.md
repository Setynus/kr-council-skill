# 동결 기준선 (2026-11-10 확보)

교차 비교 평가에서 ecc가 삭제돼도 재현할 수 있도록, ecc가 설치돼 있는 시점에 한 번만 실행해 출력만 저장한 파일이다. 이 폴더의 파일은 다시 만들지 않고 그대로 비교에 쓴다.

## 파일 규칙
`<질문ID>.<시스템키>.md` (질문은 `../questions.md`의 q01~q10)

| 시스템키 | 내용 | 개수 |
|---|---|---|
| `ecc-council` | `ecc:council` 스킬을 그대로 실행한 최종 출력(네 입장 + Verdict) | q01~q10 (10) |
| `single` | 스킬 없이 한 번 답한 단일 답변 | q01~q10 (10) |
| `orig-method` | 원본 방식(5인 자문 → 익명 상호 검토 → 의장 종합)의 의장 판정만 | q01~q03 (3) |
| `kr-council-skill` | 이 프로젝트 스킬의 출력(Task 9에서 추가) | q02, q03, q09 (3) |

## 실행 조건
- 실행일: 2026-11-10. 질문 한 건씩 독립된 하위 에이전트로 실행(질문 외 맥락 없음). 세션 언어가 한국어라 출력도 한국어다.
- 모델: 하위 에이전트 기본 모델(세션 모델과 동일). 정확한 모델명은 하네스가 하위 에이전트에 노출하지 않아 기록하지 못했다.
- ecc: 버전 2.2.3, 커밋 `d2ef268`(2026-11-06), 위치 `~/.claude/plugins/marketplaces/ecc`. 스킬 본문은 저장소에 복사하지 않았고 **실행 결과만** 보관한다.
- `orig-method`: 원본 저장소의 프롬프트 문장은 쓰지 않고, 방식(5개 관점, 익명 A~E 검토 3문항, 의장 5개 절)만 내 문장으로 지시해 실행했다. 질문당 약 11회 하위 호출이 들어서 3개 질문만 실행했다.

## ecc 라이선스
ecc는 MIT License(Copyright (c) 2026 Affaan Mustafa)이다. MIT는 사본 사용·보관을 허용하며, 스킬 본문을 복사하지 않고 출력만 보관하는 이 방식은 라이선스 조건과 충돌하지 않는다.

## `ecc:council-multi-model` 기준선: 없음 (external review absent)
- 이 스킬은 `ecc:council` 결과에 OpenAI Codex의 외부 비판을 한 번 더하는 확장이며, council 부분은 `ecc-council`과 같다.
- 확인 시점(2026-11-10)에 설치된 Codex CLI는 ecc 어댑터가 요구하는 0.146.0과 다른 버전이다. ecc 어댑터(`scripts/review-with-codex.js`)는 `SUPPORTED_CODEX_VERSION = '0.146.0'`만 허용하고 다른 버전은 실패 처리한다. 그래서 실행하지 않았다.
- 실행하려면 (1) Codex 0.146.0 설치, (2) 질문 내용을 OpenAI로 전송하는 것에 대한 사용자의 명시적 동의가 필요하다. 동의 없이는 실행하지 않는다.
- Antigravity CLI는 이 ecc 스킬이 지원하는 검토기가 아니므로 이 기준선에 쓰지 않는다.
