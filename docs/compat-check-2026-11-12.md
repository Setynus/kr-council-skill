# kr-council-skill 호환성 점검 (Claude Desktop Code 탭) — 2026-11-12

Desktop Code 탭에서 병렬 방식을 1회 완주한 실측 기록이다. 1회뿐이라 재현성은 미확인이다.

## 실측 결과
- 설치본(`~/.claude/skills/kr-council-skill`)은 저장소 체크아웃을 가리키는 링크였다. `${CLAUDE_SKILL_DIR}`은 절대경로로 치환됨.
- "하위 세션"은 Agent 도구(`general-purpose`) 하위 에이전트로 만들어짐. 앱의 세션 시작 기능으로 새지 않음.
- 5 + 5 + 1 호출이 각각 한 응답에 묶임(`message.id`별 Agent 호출 수 5/5/1). `tools/check_parallel.py` 통과(묶음을 실제로 찾았음).
- 하위 에이전트는 모두 백그라운드로 시작되고, 결과가 hand-back 메시지와 완료 알림으로 도착. 5개 전부 도착한 뒤 다음 단계로 진행.
- 셔플·렌더러 종료 코드 0, HTML 생성.

수정(재호출·한국어 규칙)은 문서와 테스트만 확인했고, 새 세션 실행으로는 검증하지 않았다.

## 이번 실행의 이탈
프롬프트가 SKILL.md보다 강했음("도구를 쓰지 말고", "다른 글 금지", 위원장에게 "확인 필요" 규칙). 작업 폴더 `CLAUDE.md` 맥락 읽기와 `ko-context.md`는 생략. 새 세션이 "위원회 열어줘"만 받고 스스로 같은 경로를 타는지는 미확인.

## claude.ai — 미검증 (여기서 실행 불가)
SKILL.md의 가정: 작업 폴더 `CLAUDE.md`, 상대경로 `council-reports/`, `${CLAUDE_SKILL_DIR}` 치환, `python` 명령, Agent 도구 유무 판별.
수동 점검표: `python tools/package_skill.py`로 zip을 만들어 업로드 → (1) 스킬 인식 (2) Agent 없음 시 방식 선택 질문 (3) 코드 실행 켬/끔에서 HTML 또는 마크다운 보고서 (4) 파일을 어디서 받는지 (5) 한글 깨짐.
