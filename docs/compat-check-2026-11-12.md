# kr-council-skill 호환성 점검 (Claude Desktop Code 탭) — 2026-11-12

Desktop Code 탭에서 병렬 방식을 두 번 끝까지 돌린 실측 기록이다(점검 세션에서 1회, 새 세션에서 1회). 각 1회씩이라 재현성은 제한적이다.

## 실측 결과
- 설치본(`~/.claude/skills/kr-council-skill`)은 저장소 체크아웃을 가리키는 링크였다. `${CLAUDE_SKILL_DIR}`은 절대경로로 치환됨.
- "하위 세션"은 Agent 도구(`general-purpose`) 하위 에이전트로 만들어짐. 앱의 세션 시작 기능으로 새지 않음.
- 5 + 5 + 1 호출이 각각 한 응답에 묶임(`message.id`별 Agent 호출 수 5/5/1). `tools/check_parallel.py` 통과(묶음을 실제로 찾았음).
- 하위 에이전트는 모두 백그라운드로 시작되고, 결과가 hand-back 메시지와 완료 알림으로 도착. 5개 전부 도착한 뒤 다음 단계로 진행.
- 셔플·렌더러 종료 코드 0, HTML 생성.

수정(재호출·한국어 규칙)의 효과는 새 세션 1회에서 일부만 확인됐다. 한국어 지시는 검토·위원장 프롬프트에 들어갔지만, 잘린 검토는 손으로 이어 붙인 뒤 뒤늦게 재호출로 바로잡혔다. 규칙이 처음부터 지켜졌다고는 확인되지 않았다(이후 v0.2.2에서 확인 단계를 보강).

## 새 세션 실사용 테스트와 후속 조치 (v0.2.2)
- 조건: 작업 루트 폴더에서 `start_session`으로 연 새 세션(권한 auto, effort medium). 스킬 자동 호출, 병렬 방식 선택, 비용 안내, `general-purpose` 하위 에이전트만 사용, 보고서 생성은 정상이었다.
- 위반: 검토 5개가 1개+4개로 나뉘었다(`check_parallel` 위반, 새어듦은 없음, 원인 미확인). 잘린 검토를 이어 붙여 위원장 호출과 첫 보고서까지 간 뒤에야 재호출했다. 하위 호출은 안내한 11개보다 많은 12개에 위원장 재판정이 더 들었다.
- 잘림 원인: 하위 에이전트가 `SubagentHandback` 입력의 보고 문자열 맨 끝 `"}`를 스스로 빠뜨렸다(두 실행에서 각 1건, 나머지 21건은 정상). 전달 문제가 아니다.
- 잘림·묶음 조치: 도착한 답이 끝까지 닫힌 JSON인지 확인한 뒤에야 다음 단계로 간다, 프롬프트에 닫는 따옴표·중괄호까지 쓰라고 적는다, 5개가 모두 나가기 전에는 결과를 읽지 않는다.
- 아웃사이더 최약: 1차 3/5, 2차 5/5(기준선 q02 1/5, q03 2/5, q09 0/5). 사유는 "모른다고 함, 판단 유보, 행동 제안 없음, 남의 시선을 근거로 삼음"이었다. 조치: 약한 응답의 정의를 모든 응답에 같게 적용(입장 보류·전문성 부재만으로 약하다고 하지 않고, 놓친 구체적 내용을 적게 함), 위원 정의의 아웃사이더 절에 "입장 없이 끝내기" 금지 추가.
- `minority_kept`: 두 실행 모두 위원장 프롬프트에 예시값 `true`가 들어갔고 SKILL.md에 정의가 없었다. 조치: 정의와 응답 틀을 고정(예시값 없음), 렌더러의 false 표기를 "소수 의견 없음"으로 수정.
- 기록 재생 검증(1회): 2차 실행의 위원 답에 새 검토 프롬프트를 적용하니 아웃사이더 최약이 2/5로 줄고(이전 5/5) `weakest_why`가 놓친 구체적 내용을 적었다. 1차 데이터에 새 위원장 프롬프트를 적용하니 전원이 같은 방향에서 `minority_kept: false`가 나왔다. 한계: 1회, 같은 모델, 프롬프트를 파일로 전달함, 위원 정의 변경과 잘림·묶음 규칙은 이 재생으로 확인하지 못함. 하위 호출 6개에 약 92만 토큰.

## 이번 실행의 이탈
프롬프트가 SKILL.md보다 강했음("도구를 쓰지 말고", "다른 글 금지", 위원장에게 "확인 필요" 규칙). 작업 폴더 `CLAUDE.md` 맥락 읽기와 `ko-context.md`는 생략. 새 세션 1회에서는 "위원회 열어줘"류 요청만 받고 스스로 스킬을 호출해 같은 경로를 탔다. 다만 그 세션은 `start_session`으로 열었고 배경 문장에 "스킬 절차대로 처리"라는 유도가 있었다.

## claude.ai — 미검증 (여기서 실행 불가)
SKILL.md의 가정: 작업 폴더 `CLAUDE.md`, 상대경로 `council-reports/`, `${CLAUDE_SKILL_DIR}` 치환, `python` 명령, Agent 도구 유무 판별.
수동 점검표: `python tools/package_skill.py`로 zip을 만들어 업로드 → (1) 스킬 인식 (2) Agent 없음 시 방식 선택 질문 (3) 코드 실행 켬/끔에서 HTML 또는 마크다운 보고서 (4) 파일을 어디서 받는지 (5) 한글 깨짐.
