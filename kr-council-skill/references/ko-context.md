# 한국 맥락 체크리스트

질문이 아래 항목에 걸리면, 해당 줄을 위원 프롬프트의 맥락에 한 줄로 넣는다. 걸리지 않는 항목은 넣지 않는다.

**제도와 수치는 해마다 바뀐다.** 기억에서 꺼낸 세율·한도·기준 금액은 단정하지 말고, 위원이 쓸 때는 "확인 필요"를 붙이게 한다.

| 영역 | 해당되면 프롬프트에 넣을 한 줄 |
|---|---|
| 금액 | 금액은 원화(만 원·억 원) 기준이며, 환율이나 달러 가정을 쓰지 않는다. |
| 세금 | 부가가치세(간이/일반과세)와 소득세, 종합소득세 신고, 세무사 비용을 함께 고려한다. 기준 금액은 확인 필요. |
| 4대 보험 | 직장가입자와 지역가입자 차이, 사업자의 보험료 부담을 고려한다. |
| 개인정보 | 개인정보보호법상 수집 동의, 보관 기간, 국외 이전 제한을 고려한다. 법적 판단은 전문가 확인이 필요하다. |
| 노동 | 근로기준법, 퇴직금, 근로시간 규정이 걸리는지 보고, 수치는 확인 필요로 표기한다. |
| 플랫폼 | 네이버 스마트스토어, 쿠팡, 카카오, 토스 등 한국 플랫폼의 수수료·정산·정책 의존을 고려한다. |
| 주거 | 전세·월세·전세대출, 보증금 보호, 주택청약 같은 한국 주거 제도를 고려한다. |
| 진로 | 공무원 시험, 병역, 대기업·스타트업 이직, 스톡옵션 과세 같은 한국 진로 사정을 고려한다. |
| 관계 | 직장 위계, 체면, 가족·지인 관계에서 거절하거나 변경하는 비용을 고려한다. |
| 전문가 비용 | 세무사·노무사·변호사 상담 비용이 질문자에게 부담인지 고려한다. |
| 최신성 | 특정 연도의 정책·수치는 틀릴 수 있으니 "확인 필요"로 적고, 확인 방법(국세청, 고용노동부, 해당 플랫폼 공지)을 함께 제안한다. |
