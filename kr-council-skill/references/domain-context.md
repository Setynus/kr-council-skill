# 영역별 확인 범주

질문이 아래 영역에 걸리면 해당 행만 읽는다. 사실 확인(1.5단계)에서 비교 대상 **모두에 같은 범주**를 조사한다. 범주는 질문 정리 때 맥락에 한 줄로 더한다. 특정 업체·상품·정치적 입장은 적지 않는다.

| 영역 | 확인할 사실 범주 | 자주 바뀌는 항목 | 주의 |
|---|---|---|---|
| 여행 | 입국·비자 요건, 항공, 숙박, 현지 식비·교통, 안전 정보, 결제·통신, 시기·날씨 | 항공·숙박 요금, 환율, 입국 정책 시한 | 해외 통화는 원화 환산·환율 기준일 표기 |
| 소비·제품 구매 | 가격, 재고·출시 일정, 보증·AS, 호환성, 유지비 | 가격, 프로모션, 후속 모델 출시 | 후기는 비공식 출처로 표기, 광고 가능성 |
| 학업·진학 | 모집 요강·일정, 비용, 졸업 요건, 진로 현황 | 모집 일정, 등록금 | 공식 요강 우선 |
| 주거·이사·지역 | 시세·거래 통계, 대출·보증 요건, 교통·생활권, 규제, 임대차 보호 요건(확정일자·대항력·보증보험) | 금리, 대출 규제, 시세 | 지역 공식 통계 우선, 개인 재정은 사용자 제시, 임대차는 고위험에 준해 전문가 확인 |
| 건강·의료 (고위험) | 공공 보건 기관의 일반 정보, 진료·검사 비용 체계 | 지침 개정 | 진단·치료 결정 아님, 전문가 확인 필수, 위기 신호는 소집 중단 |
| 가족·육아 | 지원 제도, 시설·기관 운영 현황, 비용 | 지원 요건·신청 기간 | 신청 기간·시한 확인 |
| 공공·행정 | 현행 법령, 자치법규, 상위 지침, 시행일 | 개정·시행일 | 상위 지침과 충돌하면 충돌 지점을 먼저 지적(법령 전용 조회 도구 우선), 현행과 시행 예정 구분 |
| 금융·투자 (고위험) | 금리·수수료·상품 조건, 세제, 규제 | 금리, 세제 | 수익 단정 금지, 전망은 사실이 아님, 전문가 확인 |
| 사업·창업 | 인허가, 플랫폼 수수료·정책, 지원사업, 세무 | 수수료·정책 개정 | 한국 제도는 `ko-context.md`와 함께 본다 |
| 해외 제도 | 해당 관할의 법령·세제·비자, 환율 | 개정·시한 | 한국 체크리스트 비적용, `assumptions`에 관할 표기 |
